# FreeSaveVideo 日语页面审查

检查日期：2026-10-08。检查目的：评估翻译覆盖、语义准确性及日本用户阅读时的自然程度。此次未修改产品文案。

后续实施：用户确认修改后，已完成本报告中主要文案问题的修正。以下保留原始审查记录；实施结果见文末。

## 结论与范围

翻译资源的键覆盖完整，但整站仍有硬编码英文；文案质量不均。首页主标题及较新的 YouTube 保存指南可读性较好，旧导航、FAQ、设置说明和部分 SEO 工具介绍有明显直译痕迹。建议先修正功能名称、付费含义与货币展示，再进行日本推广。

线上实际检查：首页 `/ja`、FAQ `/ja/faq`、YouTube 指南 `/ja/guide/youtube-download-guide`。源代码抽查：导航、首页、下载、设置、格式转换、FAQ、账户付费、SEO 运行时文案及关于页面。没有逐项触发全部错误弹窗，没有进行支付或完整下载测试；其余工具与所有平台页面未逐页验收。

## 覆盖检查

- 日语目录包含 34 个 JSON 文件（包括 6 个无障碍文案文件），另有 8 个 about Markdown 文件。
- 以英文资源为基准，检查了 2,083 个字符串键：没有缺键，没有空字符串。
- `pnpm -C web i18n:check-completeness` 通过。
- `pnpm -C web i18n:check-encoding` 通过；没有发现 UTF-8 损坏。
- 这些检查只证明资源结构完整，不能证明每个页面都已翻译、日语自然或产品说明准确。Svelte 中的中英二选一分支不在上述统计内。
- 部分 SEO 路由按语言策略仅提供英文或中文，不宜把 JSON 键覆盖称为“整站日语完成度 100%”。参见 `web/src/lib/seo/internal-links.ts:312`。

## 日语资源之外的遗漏

- 日语首页实际显示英文链接「Personal AI agents supported: integration guide」。源码 `web/src/routes/[lang]/+page.svelte:894` 只区分中文与其他语言。
- 账户源码 `web/src/routes/[lang]/account/+page.svelte` 的记录中心、推广记录、反馈记录、表头与审核状态存在同类中英分支，如「Record Center」「Promotion Records」「Submitted At」「Pending」「Submit for review」。这些路径需要迁入翻译资源；本次没有逐项进入已登录页面进行线上验收。
- 首页及 FAQ 部分无障碍标签仍为英文，如「Download guides」「FAQ tools」。可见文案和读屏标签应一起检查。

## 需要同步产品事实的文案

首页写「広告なし」，而关于/FAQ 文案提到官方站使用广告与分析服务；设置内另有较旧的隐私分析说明。这里只确认文案相互不一致，没有对实际广告运行及隐私合规作判断。应先确认当前服务事实，再统一各语言，避免仅润色日语保留旧信息。

推广奖励条件写「80語以上」，日语通常没有像英文一样明确的空格分词。需要定义日语稿件的计算规则并解释给用户，不能直接把 80 词改成 80 字而改变业务条件。

## 建议的修改顺序

1. 统一功能名称、会员要求、货币展示与 FAQ 操作按钮名称。
2. 校对首页、FAQ、账户及日本用户常用平台的落地页；补齐硬编码英文和读屏文案。
3. 润色设置、辅助工具、SEO 长文，核对广告/隐私及推广规则中的产品事实。
4. 修改后重跑完整性与编码检查，并实际验收登录、保存、错误提示和付款展示。此次没有运行构建。
